👑 مدير الشركة (Company Admin)

يملك صلاحيات مطلقة على مستوى الشركة: إنشاء الفرق، تعيين وحذف مدراء الأساطيل، إدارة المستودع العام للمركبات والسائقين، والاطلاع على الإحصائيات المالية والتشغيلية الشاملة.

👔 مدير الأسطول (Fleet Manager)

مرتبط بفريق تشغيلي محدد: يدير سائقي ومركبات فريقه، ينشئ المهام اللوجستية ويتابع تنفيذها، ويعتمد فواتير الوقود وسجلات الصيانة الخاصة بفريقه فقط.

🚚 السائق الميداني (Driver)

يستقبل المهام المسندة إليه، يبدأ المهمة وينهيها، ويسجل قراءات العداد وإيصالات الوقود وبلاغات الصيانة المرفقة بالصور المعتمدة.

🛡️ قواعد العمل التشغيلية الصارمة (Strict Business Rules)

مجموعة الضوابط البرمجية والمعمارية المطبقة في الباك إند والفرونت إند لمنع التداخل وضمان سلامة البيانات:

1. قاعدة ربط السائق بالمركبة (Same-Team Rule): لا يمكن نهائياً ربط سائق بمركبة إلا إذا كان كلاهما منضماً لنفس الفريق التشغيلي (driver.teamId === vehicle.teamId). يمنع ربط سائق أو مركبة موجودين في المستودع العام (بدون فريق).
2. العزل المتعدد للمستأجرين (Multi-Tenant Isolation): كل استعلام يتم تصفيته تلقائياً بواسطة companyId المستخرج من الـ JWT Token الموثق. لا يمكن لأي مستخدم الوصول لبيانات شركة أخرى.
3. نطاق مدير الأسطول (Scoped Team Access): مدير الأسطول (Fleet Manager) محصور بصلاحيات فريقه التشغيلي فقط؛ يتم استخراج teamId الخاص به تلقائياً عبر Middleware لمنع الوصول لمركبات أو مهام الفرق الأخرى.

1. المصادقة وإدارة الجلسات (Authentication)

المسارات المسؤولة عن تسجيل الحسابات، التحقق، إصدار الرموز الأمنية، وإدارة دورة حياة الـ JWT.

POST /api/auth/signup
Public

إنشاء حساب شركة جديد وتعيين المستخدم كـ Admin للشركة. يتم إنشاء سجل الشركة تلقائياً وتفعيل الحساب.

الحقل (Field) النوع الحالة الوصف
email String مطلوب البريد الإلكتروني للشركة (فريد)
password String مطلوب كلمة المرور (6 أحرف على الأقل)
Request Example (JSON) 
{
  "email": "admin@logistics-corp.com",
  "password": "SecurePassword123!"
}
POST /api/auth/login
Public

تسجيل الدخول وإصدار Access Token (مدته 15 دقيقة) و Refresh Token مشفر يتم تخزينه في HttpOnly Cookie.

Response Example (200 OK) 
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "_id": "64f1a2b3c4d5e6f7a8b9c0d1",
      "email": "admin@logistics-corp.com",
      "role": "ADMIN",
      "companyId": "64f1a2b3c4d5e6f7a8b9c0d2",
      "status": "active"
    }
  }
}
POST /api/auth/onboarding
Admin Only

إكمال إعداد حساب الشركة بعد التسجيل مباشرة لتحديد اسم الشركة الرسمي ورقم السجل التجاري.

الحقل النوع الحالة الوصف
name String مطلوب اسم الشركة أو المؤسسة الرسمي

2. الحساب والملف الشخصي (User & Session)

إدارة جلسة المستخدم الحالية، تعديل البيانات الشخصية، وتحديث حالات المستخدمين في المنظومة.

GET /api/user/me
Authenticated

جلب بيانات المستخدم الحالي، الشركة التابع لها، الدور الوظيفي، والفريق المعين عليه إن وجد.

Response Example
{
  "success": true,
  "data": {
    "user": {
      "_id": "67be1c2579124430e3bb4a79",
      "email": "manager@zemam.sa",
      "name": "سليمان القحطاني",
      "role": "FLEET_MANAGER",
      "companyId": "67be1c0079124430e3bb4a72",
      "teamId": "67be2a1079124430e3bb4b11",
      "status": "active"
    }
  }
}
PATCH /api/user/:id/status
Admin Fleet Manager

تغيير حالة المستخدم بين مفعل (active) ومعطل (inactive).

الحقل النوع القيم المسموحة
status String active | inactive

3. إدارة مدراء الأساطيل (Fleet Managers)

خاص بـ Admin الشركة لإنشاء مدراء الأساطيل وإسنادهم للفرق التشغيلية.

GET /api/user/fleet-manager
Admin Only

جلب قائمة مدراء الأساطيل التابعين للشركة مع دعم فلتر المدراء غير المرتبطين بأي فريق.

Query Param النوع الوصف
withoutTeam Boolean string إذا كانت "true"، يرجع فقط المدراء غير المعينين على أي فريق
status String تصفية حسب الحالة (active / inactive)
POST /api/user/fleet-manager/:id/team
Admin Only

تعيين مدير أسطول كمسؤول رسمي عن فريق تشغيلي محدد. يتم تحديث سجل الفريق وسجل المدير بشكل متزامن.

Body Param النوع الحالة الوصف
teamId MongoId مطلوب معرف الفريق المراد إسناد الإدارة إليه
POST /api/user/fleet-manager/:id/remove-from-team
Admin Only

فك ارتباط مدير الأسطول عن فريقه وإعادته لقائمة المدراء المتاحين (المستودع العام للمدراء).

4. إدارة السائقين وربط المركبات (Drivers)

المسارات المتكاملة لإضافة السائقين، تعيينهم على الفرق، وربطهم بالمركبات.

GET /api/user/driver
Admin Fleet Manager

عرض قائمة السائقين. يرى الـ Admin كافة سائقي الشركة أو المصفين، بينما يرى الـ Fleet Manager سائقي فريقه فقط.

Query Param النوع الوصف
withoutTeam Boolean تصفية السائقين غير المنضمين لأي فريق (المستودع العام)
POST /api/user/driver/:id/assign-to-vehicle
Admin Fleet Manager
شرط إلزامي: يجب أن يكون السائق والمركبة منضمين لنفس الفريق التشغيلي (driver.teamId === vehicle.teamId).
Body Param النوع الوصف
vehicleId MongoId معرف المركبة التابعة لنفس فريق السائق
POST /api/user/driver/:id/remove-from-vehicle
Admin Fleet Manager

فك ارتباط السائق عن مركبته الحالية وتفريغ حقل driverId في المركبة.

POST /api/user/driver/:id/assign-to-team
Admin Only

ضم السائق إلى فريق تشغيلي محدد (يتم فك ارتباطه بالمركبة السابقة إذا كانت في فريق آخر).

Body Param النوع الوصف
teamId MongoId معرف الفريق التشغيلي المستهدف
POST /api/user/driver/:id/remove-from-team
Admin Only

فك ارتباط السائق عن فريقه ونقله للمستودع العام وفك ارتباطه عن أي مركبة مرتبطة به.

5. الفرق التشغيلية (Operational Teams)

وحدات العمل المركزية التي تجمع بين مدير أسطول، مجموعة سائقين، وأسطول مركبات مستقل.

POST /api/team
Admin Only

إنشاء فريق تشغيلي جديد وتعيين المدير والسائقين والمركبات الأولية دفعة واحدة.

Field Type Status Description
name String مطلوب اسم الفريق (6 أحرف على الأقل)
managerId MongoId اختياري معرف مدير الأسطول المخصص
driversIds Array<MongoId> اختياري مصفوفة بمعرفات السائقين لضمهم للفريق
vehiclesIds Array<MongoId> اختياري مصفوفة بمعرفات المركبات لضمها للفريق
GET /api/team/statics
Admin Fleet Manager

جلب الإحصائيات التشغيلية الخاصة بالفريق: عدد السائقين، المركبات العاملة، المهام المنجزة، واستهلاك الوقود.

6. أسطول المركبات (Vehicles Management)

إدارة شاحنات ومركبات الأسطول، تعيين الفرق، تحديث الحالات، والحذف الناعم.

GET /api/vehicle
Admin Fleet Manager

جلب قائمة مركبات الأسطول مع دعم تصفية مركبات المستودع العام (withoutTeam=true).

POST /api/vehicle/:id/assign-to-team
Admin Only

إسناد مركبة من المستودع العام إلى فريق تشغيلي محدد لتصبح جاهزة لتعيين سائق وتلقي المهام.

DELETE /api/vehicle/:id
Admin Fleet Manager

حذف المركبة ناعماً (Soft Delete عبر isDeleted: true) وفك ارتباط السائق والفريق عنها تلقائياً.

7. المهام والتوزيع اللوجستي (Tasks Dispatch)

دورة حياة المهام التشغيلية: إنشاء، تكليف، قبول من السائق، وإنهاء.

POST /api/task
Admin Fleet Manager

إنشاء مهمة نقل جديدة وتكليف سائق ومركبة نشطين تابعين لنفس الفريق التشغيلي.

Field Type Status Description
description String مطلوب تفاصيل المهمة ونقاط التسليم
driverId MongoId مطلوب معرف السائق النشط في الفريق
vehicleId MongoId مطلوب معرف المركبة النشطة في الفريق
PATCH /api/task/:id/accept
Driver Only

قبول المهمة من تطبيق السائق وتحويل حالتها إلى inProgress لبدء التنفيذ والتحرك الميداني.

PATCH /api/task/:id/finish
Driver Only

إنهاء المهمة بعد اكتمال التسليم بنجاح وتحويل حالتها إلى finished.

8. الوقود وبلاغات الصيانة (Operations & Telematics)

تسجيل استهلاك الوقود وفواتير الديزل وبلاغات الأعطال المرفقة بالصور المعتمدة.

POST /api/fuel
Driver Only (Multipart)

يقوم السائق برفع فاتورة تعبئة وقود مع صورة العداد والإيصال وتحديد التكلفة واللترات.

Field (FormData) Type Description
cost Number تكلفة التعبئة بالريال
liters Number كمية الوقود باللتر
odometer Number قراءة عداد الكيلومترات الحالية
image File صورة إيصال المحطة (Cloudinary)
POST /api/maintenance
Driver Fleet Manager

تسجيل طلب أو فاتورة صيانة مع إمكانية رفع حتى 4 صور للأعطال وقطع الغيار المستبدلة.

9. إحصائيات المنظومة والشركة (Company Analytics)

لوحة المؤشرات والتحليلات الشاملة لمالك ومدير الشركة.

GET /api/company/statics
Admin Only

إرجاع الملخص الإحصائي الكلي للشركة: إجمالي الفرق، الأسطول، السائقين، نسب الإنجاز، وإجمالي النفقات التشغيلية.
